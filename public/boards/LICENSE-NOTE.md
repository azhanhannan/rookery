# Board textures

The textured boards (`wood.jpg` = Oak, `wood2` = Teak, `wood3` = Birch, `wood4` = Cherry, `maple` = Maple,
`maple2` = Burl, `marble` = Jade, `blue-marble` = Marble, `leather`, `metal`, `olive`, `canvas2` = Canvas,
`green-plastic` = Plastic) were taken unchanged from the Lichess repository (`lichess-org/lila`, commit `ad76013`,
`public/images/board/`) by `scripts/fetch-boards.mjs`.
